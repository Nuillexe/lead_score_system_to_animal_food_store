# 🐾 Lead Scoring System for Pet Shop

Web application developed with Django to collect, evaluate, and classify potential customers (leads) for a pet shop.

🔗 Live Demo: https://lead-score-system-to-animal-food-store.onrender.com

---

## 📌 About

This project is a **Lead Scoring system** designed to help a pet shop identify and prioritize potential customers based on their profile and responses to a form.

It was developed as part of the **OSM (Organização, Sistemas e Métodos)** course at university.

---

## 🚀 Features

- 📋 Lead evaluation form
- 📊 Automatic scoring system
- 👤 Authentication system (login/logout)
- 🔐 Admin panel (Django Admin)
- 🧠 Classification of leads based on responses
- 📦 Data persistence (database)
- 🌐 Deployed on Render

---

## 🛠️ Technologies

- Python
- Django
- HTML / CSS
- SQLite (development)
- Gunicorn (production)
- WhiteNoise (static files handling)
- Render (deployment)
